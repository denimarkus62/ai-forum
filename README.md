# ИИ и вайбкодинг: форум-подборка

Статичная страница в виде форума: разбор постов Telegram-канала [«Женя Глобус»](https://t.me/eugene_globus) по состоянию на 30.09.2026. Темы, пошаговые инструкции, готовые промпты. Писать сообщения на странице нельзя.

Пересказ сделан своими словами, оригиналы по ссылкам в темах. Страница закрыта от индексации (robots.txt и meta noindex).

## Как обновлять
- Все темы лежат в `data.js`, разметка и логика в `index.html`, `app.js`, `style.css`.
- Новая тема: добавить объект в массив `topics` в `data.js` (поля `id`, `cat`, `title`, `date`, `posts`).
- Файлы открываются только через веб-сервер (GitHub Pages), двойным щелчком по index.html скрипты могут не работать.
